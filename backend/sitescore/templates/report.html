How the scores work

AI agent readiness: six checks share 100 points, based on open standards that AI assistants and agents use to find and read sites. llms.txt is shown but not scored.

Website health: each check is worth a share of 100 points, with more for the checks that matter most. A serious problem, such as an exposed password file, holds the score below 50.

SiteScore checks only public information. It is guidance, not a full security audit.
